## Overview

WellSave is a financial planning platform designed to help women manage family finances while balancing work, childcare, and household responsibilities.

The platform combines an AI-based financial planner with tools that simplify budgeting and saving decisions.

![WellSave overview](/images/wellsave-overview.jpg)

## Problem

Managing household finances can be challenging for individuals with busy daily routines.

Many financial tools require significant time and attention, making them difficult to use consistently for people managing multiple responsibilities.

![Problem illustration](/images/wellsave-problem.jpg)

## User Journey

A user journey map was created to understand how users manage finances throughout their daily routines.

Insights from the journey revealed that users often check financial information quickly between other tasks, highlighting the need for simple and fast interactions.

![User journey](/images/wellsave-journey.jpg)

## Design Process

Design exploration focused on simplifying financial information and providing personalized insights through AI-assisted features.

Key considerations included:

- Clear financial summaries
- Easy budgeting tools
- Personalized financial guidance

Prototypes were created to test how users interact with financial dashboards and recommendations.

![Design process](/images/wellsave-wireframe.jpg)

## Solution

WellSave provides a financial ecosystem that helps users manage money more efficiently.

Key features include:

- AI-based financial planning
- Personalized financial profiling
- Budget tracking and insights
- Social saving through RoSCA-inspired mechanisms

![Final UI](/images/wellsave-ui.jpg)

## Reflection

This project highlighted how financial tools can be redesigned to support users with busy lifestyles. Simplifying financial data and providing personalized guidance can help users make more confident financial decisions.
